Number Translation Rules

Rules run top to bottom, separately on the A-number (Sender ID) and the B-number (Destination), just before the message is sent to this carrier. The original numbers from the client are always kept on the SMS log; the transformed values are recorded as the dispatched values. Order matters (for example: remove +, remove leading zeros, then add a country prefix).
